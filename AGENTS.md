# Контекст проекта

Всегда отвечай пользователю на русском языке.

Локальное приложение анализа командного домино «Козёл». Node.js 22+, JavaScript ESM,
встроенные HTTP-сервер и node:test. Расчёты — в браузерном Web Worker,
backend — хранение компактных результатов. Веб-интерфейс без сборки.

## Правила

- Перед изменением поведения прочитай [правила OpenSpec](.agents/rules/OPENSPEC_RULES.md).
- Применимые подробности: [код и архитектура](.agents/rules/REVIEW_RULES.md),
  [проверки](.agents/rules/UNIT_TEST_RULES.md), [инструменты](.agents/rules/TOOL_USAGE_RULES.md),
  [коммиты](.agents/rules/COMMIT_STRUCTURE_RULES.md).
- Проверяй JSON, порядок ходов, начисления и сохранение всех 28 камней.
- Источник актуальных правил и формата игры — [Veselchak-U/domino_spec](https://github.com/Veselchak-U/domino_spec).
  Перед работой с игровыми правилами или контрактом JSON сверяйся с ним и обновляй
  локальные материалы по [порядку синхронизации](docs/game-spec-source.md).
- Аналитический победитель рыбы отличается от winner_team исходного журнала:
  при завершении партии — победитель партии, иначе — команда рыбака.
- Только точный полный перебор. Дедупликация одинаковых продолжений одного узла,
  кеш в памяти и точные счётчики BigInt обязательны. Не подменяй расчёт выборкой.
- При работе над оценкой ходов, статистикой, объяснениями и дашбордом обращайся к
  [каталогу внешних источников](docs/domino-analysis-sources.md): выбирай материалы
  по задаче, проверяй актуальный код и отличия правил. Идеи источников не меняют
  принятую модель расчёта и контракт проекта без отдельного изменения OpenSpec.
- Не изменяй исходные пользовательские JSON и соседние проекты. Игровые данные
  передаются только выбранному владельцем серверу библиотеки; внешние сервисы
  и телеметрия их не получают.
- Сохраняй чужие изменения. Не коммить и не публикуй без явного запроса.
- В интерфейсе, сообщениях и документации используй термин «раунд» для одной раздачи партии.

## Команды

`npm ci`, `npm test`, `npm run check`, `npm start`.

Исходный код — src/, интерфейс — public/, тесты — test/,
контракт входа — contracts/, спецификации — openspec/.
