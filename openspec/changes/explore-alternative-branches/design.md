## Context
src/server.js владеет играми, кешем готовых результатов и единственным worker. analyzeRound сейчас строит только реальные префиксы. Каталог docs/domino-analysis-sources.md: DominoGPT и abw333/dominoes показывают линии minimax; наши W/N — иная мера, minimax и отсечения не переносятся.

## Goals / Non-Goals
Исследование проверенного пути от реальной позиции. Без редактора независимых рук BL-25, без предположений о человеческой политике и без нового критерия оптимальности.

## Decisions
POST /api/branch принимает gameId, round, position, moves и необязательный example win/loss/draw. Сервер валидирует форму и размер (до 128 действий), worker повторно воспроизводит путь из parseGame. Общий анализ истории выделяется из analyzeRound, чтобы состав, facts и точность оставались едиными. Ветка имеет собственные steps и metadata origin/path/referenceTeam; actual означает выбранный путь и в UI называется продолжением примера, не «В игре».

Worker владеет точным solver-кешем только на время запроса; готовый результат кешируется сервером по всем параметрам в общей ограниченной коллекции. Следующий отличный путь пересчитывает дерево из своей исходной позиции; это сохраняет простой жизненный цикл и ограничение одного worker. Пример продолжается из конца выбранного пути; выбирается первый ребёнок с ненулевым wins целевого аналитического победителя. Отсечения дерева для подсчёта не используются.

UI app.js владеет отдельным состоянием branch; реальная analysis/stepIndex не меняются. Старый результат сохраняется до успешного нового расчёта. Ошибка и отмена не стирают его. Возврат отменяет активный запрос и восстанавливает dashboard. Отдельный экран не рисует гипотетические точки на реальных графиках.

## Risks / Trade-offs
Рост времени/памяти полного дерева → существующий ограниченный кеш и отмена; без выборки. Невозможный целевой исход → сообщение. Смешение победителя рыбы → использовать settle/analyticsWinner. Исходная команда для win/loss фиксируется в origin, не меняется с очередью. При вычислении кнопки перехода блокируются, отмена и возврат остаются доступны.
