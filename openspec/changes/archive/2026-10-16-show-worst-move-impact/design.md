## Context

worst.impact уже содержит вклад худшего допустимого действия для команды автора,
выбранный по точным долям. Требуется только отобразить существующие данные.

## Goals / Non-Goals

Goals: три различимые серии и понятные значения. Non-Goals: менять расчёт,
добавлять отдельный плохой розыгрыш или включать альтернативы в итоги игроков.

## Decisions

- Использовать готовый worst.impact без повторного расчёта и нового состояния.
- SVG pattern с кругами в цвете игрока на белом фоне отличает худший вариант
  от диагонального pattern лучшего и сплошного реального столбца.
- Смещения центров −20/0/+20 при ширине 14 сохраняют шаг 64 px.
  Добавить строку «Худший» и увеличить высоту SVG до 365 для подписей автора/шага.
- Группа остаётся одним доступным элементом выбора; описание содержит все три
  вклада и действия альтернатив, оба графика используют прежний chartX.

## Risks / Trade-offs

Большой худший вклад уменьшает визуальные высоты остальных → общая симметричная
шкала включает все серии, числовые подписи остаются видны.
