## Purpose

Обеспечить повторяемую установку текущего приложения на локальной Linux VM, закрытый доступ через SSH и обновление готовыми контейнерными релизами с откатом.

## ADDED Requirements

### Requirement: Локальная контейнерная поставка
Приложение SHALL запускаться на локальной Linux VM через Docker Compose готовым версионированным образом. Поставляемый архив MUST NOT включать пользовательские журналы, секреты и соседние проекты. На хост VM SHALL публиковаться только loopback-порт 3210. Доступ владельца SHALL обеспечиваться через SSH-туннель. По умолчанию обычный запуск Node SHALL оставаться на loopback.

#### Scenario: Контейнерная сеть
- **WHEN** приложение запущено с явным адресом 0.0.0.0 внутри контейнера и host port привязан к 127.0.0.1
- **THEN** loopback-запрос и SSH-туннель получают приложение, неверные Host и Origin отклоняются

#### Scenario: Состав релиза
- **WHEN** собран архив версии приложения
- **THEN** в нём готовый образ и управление запуском, без исходных пользовательских JSON и секретов; рабочей VM не нужна сборка исходников

### Requirement: Управляемое обновление
Установка и обновление SHALL проверять целостность релиза и загружать образ до замены текущего контейнера. Успешным SHALL считаться только здоровый запуск. Ошибка нового контейнера SHALL приводить к попытке запуска прежнего релиза и явному сообщению о результате. Повторное использование номера версии с иным содержимым SHALL отклоняться. Операции SHALL исключать одновременное обновление и не удалять данные.

#### Scenario: Ошибка доставки
- **WHEN** checksum не совпал или образ не загрузился
- **THEN** текущий контейнер не заменяется, команда возвращает ненулевой код

#### Scenario: Новый запуск не здоров
- **WHEN** после обновления healthcheck не прошёл
- **THEN** выполняется запуск прежней версии, успешность отката проверяется отдельно, ошибка обновления остаётся видна

#### Scenario: Откат и каталог данных
- **WHEN** владелец откатывает успешное обновление
- **THEN** запускается предыдущий образ, внешний каталог данных сохраняется, инструкция не обещает сохранения игр и расчётов в памяти
