## Why

Нужно воспроизводимо устанавливать и обновлять текущее приложение на локальной Linux VM, прежде чем выбирать облако и разделять приложение на сервисы.

## What Changes

- Контейнер приложения Node.js и Docker Compose для Ubuntu 24.04 LTS linux/amd64.
- Явная настройка адреса прослушивания для Docker при сохранении локального запуска по умолчанию и защиты Host/Origin.
- Версионированный архив релиза, установка, обновление готовым образом, проверка здоровья и откат.
- Только loopback-порт VM и SSH-туннель. Никаких облачных аккаунтов, ресурсов или внешнего размещения.
- Отдельный каталог данных для локальных примеров и резервных копий. Память игр/анализа пока не становится постоянной; инструкция объясняет сброс при перезапуске.

## Capabilities

### New Capabilities

- `local-vm-deployment`: локальная контейнерная поставка, установка и обновление.

### Modified Capabilities

Нет. Действующие игровые правила, API и модель расчёта сохраняются.

## Impact

Новый каталог deploy/vm, тесты сетевой конфигурации и управления релизами, небольшая настройка запуска src/server.js и инструкция. Исходные JSON и соседние проекты не затрагиваются. Разделение сервисов, БД, авторизация публичного приложения и облачное развёртывание отложены.
