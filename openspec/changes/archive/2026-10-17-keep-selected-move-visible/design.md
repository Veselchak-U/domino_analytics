## Context

Оба SVG находятся в общем горизонтальном контейнере. Все средства навигации вызывают selectStep; renderStep пересоздаёт группы SVG. См. proposal.md.

## Goals / Non-Goals

Сохранять выделенную группу в области просмотра без изменения аналитического состояния и без вертикального перемещения страницы.

## Decisions

После renderStep в selectStep измерять новую группу [data-step] и видимую ширину контейнера. Небольшой DOM-модуль navigation.js минимально корректирует только scrollLeft с отступом 12px и ограничением диапазона прокрутки. Если группа уже видна, запись не выполняется. Альтернатива scrollIntoView может сдвигать всю страницу, поэтому не используется. Прокрутка мгновенная, без очереди анимаций при быстрых нажатиях и без зависимости от настройки reduced-motion. Состоянием позиции по-прежнему владеет app.js, положением прокрутки — DOM.

## Risks / Trade-offs

Ошибки масштаба SVG → измерять реальные экранные координаты группы, проверять узкий экран и оба направления. Повторное создание SVG → измерять только после renderStep. Новый модуль → добавить статический маршрут и HTTP-проверку.

Проверка браузером выявила обрезание крайней группы при старом правом отступе 20px. Общий отступ обоих графиков увеличен до 40px; ширина холста и обратное преобразование клика используют те же границы. Шаг между группами сохраняется.
По снимку пользователя и измерению DOM подтверждено пересечение подсветки шага 0 с левыми подписями на 13–14px. Левый отступ обоих графиков увеличен до 120px, сетка начинается на той же границе. Подписи остаются на x=65, а подсветка начинается на x=92; между ними остаётся свободное место. Проверка выполняется для широкого и узкого экрана.

Дополнительное замечание пользователя: перед отображением альтернатив выполняется стабильная сортировка копии списка по actual. Данные анализа не изменяются. В заголовке альтернативы влияние следует за названием, actual получает margin-left:auto. Браузерная регрессия перед правкой: в позиции 1 реальный ход 5–1 показан вторым и отметка предшествует влиянию; после правки проверяется обратное. Для перестановки готовых DOM-подписей отдельный модульный тест, повторяющий стандартную сортировку, не добавляется.
