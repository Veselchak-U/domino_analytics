## Context
renderQualitySummary создаёт имена без класса; существующие классы a/b и CSS-переменные --a/--b уже определяют командные цвета в обеих темах.

## Goals / Non-Goals
Цвет только имени в сводке качества; показатели и расчёты не меняются.

## Decisions
Ячейка имени получает существующий класс classes[i % 2], поскольку game.players упорядочены по месту при импорте. Новые CSS-цвета не вводятся.

## Risks / Trade-offs
Для изменения одного класса отдельный unit-тест повторял бы реализацию. Проверка — наблюдаемое отображение и computed color всех восьми строк на реальном журнале в обеих темах, плюс общий набор проверок. До исправления фиксируется отсутствие командных классов.

Проверка 2026-10-17: до исправления все восемь имён были без класса с одинаковым цветом текста. После исправления чередуются a/b: тёмная тема rgb(98,207,186) / rgb(239,180,107), светлая rgb(0,111,98) / rgb(151,86,15). Имена партнёров совпадают по цвету в раунде и итогах партии. 113 тестов и npm run check прошли.
