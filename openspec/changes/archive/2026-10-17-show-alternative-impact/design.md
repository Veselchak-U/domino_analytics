## Context

См. proposal.md. API уже возвращает вероятности текущей позиции и каждой альтернативы; public/impact.js содержит чистые расчёты влияния.

## Goals / Non-Goals

Расширить отображение альтернатив без дополнительных вычислений дерева и изменений HTTP-контракта.

## Decisions

Чистая функция в impact.js вычисляет разницу для команды step.turn % 2 с существующей внутренней точностью. app.js использует текущий выбранный step, а не предыдущий шаг истории. Альтернатива — поле в ответе API — добавляет избыточные данные и требует изменения контракта. Значение показывается в заголовке альтернативы, положительные/отрицательные цвета используют текущую тему, ноль — обычный текст. Перенос строк сохраняет читаемость на телефоне.

## Risks / Trade-offs

Путаница команды автора предыдущего хода с командой следующего → тесты для всех четырёх мест и проверка браузером на реальном журнале. Округление скрывает малые изменения → сохранить внутренние четыре знака и существующее форматирование двух знаков.
