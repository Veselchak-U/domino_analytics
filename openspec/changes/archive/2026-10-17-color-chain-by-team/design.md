## Context
Исходная раздача содержит все 28 камней, владелец не меняется; chain хранит ориентацию каждого выложенного камня. Нынешний renderer уже сохраняет дубли и физическую ориентацию.

## Goals / Non-Goals
Только командная принадлежность цепочки без изменения solver, журнала и оформления других фишек.

## Decisions
Чистый public/domino.js строит отображение канонического камня в индекс команды из четырёх исходных рук и возвращает команды в порядке chain. Это избегает изменения HTTP-контракта и повторного воспроизведения истории в UI. app.js применяет классы и подсказку; CSS использует переменные цветов текущей темы, смешанные с нейтральной линией. Никакого отдельного состояния выбора/кеша нет. Новый статический модуль добавляется в разрешённые assets сервера.

## Risks / Trade-offs
Обратная ориентация → каноническая пара значений. Неверные данные не получают произвольный цвет → явная ошибка. Цвет сам по себе не передаёт название команды → подсказка и доступное имя. При смене темы срабатывают CSS-переменные.
