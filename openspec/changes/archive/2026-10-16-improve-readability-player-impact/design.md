## Context

Существующий API анализирует один кон. probability/delta уже имеют 4 знака.
Перебор не меняется. Партия может требовать несколько минут точного расчёта.

## Goals / Non-Goals

Goals: вклад игрока с позиции его команды, независимая от навигации итоговая
таблица, отзывчивый просмотр рассчитанного кона. Non-Goals: оценка оптимальности
ходов и причинная модель навыка игрока, относительный прирост с делением на P_до.

## Decisions

- analysis.js добавляет impact каждого шага и четыре итога playerImpacts.
  Числа суммируются как целые единицы 0,0001, используя фактическое место игрока.
- Общий чистый модуль public/impact.js содержит агрегацию и используется Node и
  браузером; сервер отдаёт его как статический ресурс. Повтор одного номера
  кона заменяет результат. Сводка возвращает complete/completedRounds и null
  вместо общего итога при неполном покрытии.
- Браузер владеет Map готовых анализов текущего документа и очередью оставшихся
  конов. Использует существующие API/worker/cache; не добавляет второй механизм
  вычислений. В момент времени запущен один запрос анализа; отмена останавливает
  очередь. Готовая история остаётся видимой; вклад до текущего шага не подменяет итог кона.
- SVG-столбцы имеют ту же геометрию оси X, что график вероятностей. На узком
  экране оба графика прокручиваются вместе, минимальная ширина зависит от числа
  шагов. Автор подписан местом P1…P4, имя доступно в легенде и описании столбца.
- Цвета: тёмный основной/вспомогательный текст и глубокие зелёный, охра,
  синий и фиолетовый. Положительный/отрицательный знак отражён высотой от нуля,
  цвет обозначает игрока. Фиксированные размеры прежнего CSS переводятся на
  согласованную шкалу, а не только меняется размер html.

## Risks / Trade-offs

По уточнению пользователя все показатели процентов форматируются с двумя знаками.
Внутреннее суммирование сохраняет точность 0,0001; округление применяется при
отображении. Малая ненулевая вероятность помечается <0,01%, практически достоверная
>99,99%, если точный счётчик показывает наличие других исходов.

- Полная партия медленнее одного кона → видимый прогресс, отмена, повтор без
  потери ранее рассчитанных конов и кеш браузера/сервера.
- Импакт может превышать 100% при суммировании → не обрезать значения;
  подпись явно объясняет сумму изменений своей команды, а не вероятность победы партии.
- Частичный итог легко принять за полный → null/прочерки до готовности всех конов.
- Проценты в обозначении разницы → показать формулу и пример 50→60 = +10%.
