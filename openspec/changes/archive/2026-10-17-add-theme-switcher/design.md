## Context

Оформление задано CSS и частью атрибутов SVG в app.js. Аналитическое состояние принадлежит app.js; см. proposal.md для мотивации.

## Goals / Non-Goals

Выделить владение предпочтением темы в маленький самостоятельный скрипт. Анализатор и игровые данные не затрагивать.

## Decisions

- theme.js — внешний синхронный скрипт в head перед CSS: выставляет data-theme до отрисовки, после DOMContentLoaded связывает кнопку. Альтернатива — модуль в app.js — допускает вспышку светлого фона.
- Единственный владелец предпочтения — theme.js, ключ localStorage domino-theme. По уточнению пользователя тёмная тема используется по умолчанию независимо от системной темы. Сбои хранилища перехватываются.
- Семантические CSS-переменные управляют поверхностями, подписями и цветами команд/игроков, в том числе внутри SVG. Смена темы не пересоздаёт графики и не касается состояния анализа. Костяшки остаются светлыми для сохранения контраста точек.
- Нет выбора в хранилище: тёмная тема; корректный выбор: восстановить; некорректный: тёмная тема; хранилище заблокировано: переключать в памяти.
- По дополнительным замечаниям пользователя внешний details FAQ заменяется на section с h2, вложенные details сохраняются. В сводке карточка числа ходов получает ширину по содержимому и максимум 520px, карточка исходов занимает остаток; на узком экране карточки располагаются друг под другом.

## Risks / Trade-offs

- Фиксированные цвета SVG могут потерять контраст → перевести их на переменные, проверить оба графика в браузере.
- Длинный заголовок на телефоне → шапка переносится, кнопка сохраняет доступную область нажатия.
