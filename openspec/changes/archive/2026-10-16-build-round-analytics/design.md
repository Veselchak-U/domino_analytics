## Context

Проект пустой. Контракт взят из domino_spec; реальные образцы — из out парсера.
Правила аналитического победителя рыбы согласованы отдельно от поля winner_team.

## Goals / Non-Goals

**Goals:** точность счётчиков, отзывчивый локальный интерфейс, повторное использование вычислений.
**Non-Goals:** прогноз будущих раздач, модель рациональной игры, публикация сервиса.

## Decisions

- JavaScript ESM / Node.js 22: доступен в среде, один runtime для HTTP, workers,
  тестов и интерфейса. Нативный движок потребовал бы отдельного компилятора и сборки.
- AJV Draft 2020-12 для исходной схемы; отдельная проверка повторных JSON-ключей
  и семантическое воспроизведение. Молчаливых исправлений нет.
- 28 камней — биты Number, руки неизменяемые. В пределах раздачи общая маска
  оставшихся камней однозначно задаёт руки. Числовой ключ добавляет концы, очередь
  и рыбака. Зеркала эквивалентны; дочерние ключи дедуплицируются до рекурсии.
- Результат узла: BigInt-счётчики побед A/B/ничьих, рыбы и яиц, максимальная глубина.
  Суммирование дочерних результатов сохраняет кратность разных путей. Сериализация
  целых в десятичные строки; только проценты округляются для показа.
- История воспроизводится независимо от анализа. Для каждого реального шага берётся
  результат соответствующего поддерева и разность вероятностей с предыдущим шагом.
  База включает все допустимые заходы назначенного игрока.

| Компонент | Владелец / состояние | Ответственность |
|---|---|---|
| game | чистые функции | допустимость ходов, раздача, счёт и исход |
| input | схема и парсер | проверка JSON и восстановление партии |
| solver | один worker | кеш поддеревьев текущего кона, полный DFS |
| server | HTTP и один активный worker | задания, прогресс, отмена, кеш готовых анализов в памяти |
| public | браузер | загрузка, график, навигация, состояние и альтернативы |

Готовые анализы кешируются по SHA-256 документа и номера кона; кеш ограничен
числом записей с вытеснением старой. Кеш узлов принадлежит одному анализу и
освобождается по завершении worker; история и альтернативы остаются в кеше
готовых анализов. Отмена прекращает worker, нет незавершённых фоновых очередей.

## Risks / Trade-offs

Реальный полный прогон выявил исчерпание памяти на втором кону журнала
2026-10-01-19-44-source-010-game-001.json при неограниченной мемоизации.
Кеш узлов ограничен двумя поколениями по миллиону записей; терминальные
агрегаты переиспользуются. Вытеснение вызывает повторный расчёт и не меняет
число листьев или точность. Регрессионный тест с кешем из 16 записей сравнивает
результат с развёрнутым перебором без кеша.

- Экспоненциальное число позиций → битовые ключи, мемоизация, прогресс, отмена;
  память конечна, ошибка ресурсов видима; выборкой результат не подменяется.
- Вероятности листьев не описывают оптимальную игру → формула явно показана в UI.
- Поле winner_team при рыбе отличается от аналитики → обе величины подписаны.
- Изменение счёта влияет на исход альтернатив → контекст счёта фиксирован на входе
  кона и включён в ключ кеша готового анализа через полный документ.

## Migration Plan

Новый локальный проект: npm ci, npm test, npm start. Миграции данных нет.
Остановка сервера удаляет только оперативный кеш, исходные журналы сохраняются.

AST Index установлен отдельно в tools/ast-index версии 3.55.0 из lock-файла
рабочего проекта-парсера. В установленной версии инкрементальное update в каталоге
без Git захватывает зависимости. Для этого небольшого проекта хуки выполняют
быстрый rebuild, который соблюдает фильтры. Это проверено по фактическим путям индекса.
Хуки postinstall/pretest/precheck/prestart не изменяют глобальные настройки инструментов.
