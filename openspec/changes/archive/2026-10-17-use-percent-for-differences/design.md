## Context

Изменяется выбранное пользователем обозначение разностей. Точные дроби, округление, статусы и формулы сохраняются.

## Decisions

Заменить подписи согласованно во всех текущих представлениях, FAQ и документации. Сохранить пример 50% → 60% = +10% и явное отсутствие относительного деления. Существующие тесты форматирования сначала должны упасть на новом ожидаемом символе, затем пройти после изменения строк; дополнительных тестов для замены подписей не требуется.

## Risks / Trade-offs

Символ % может восприниматься как относительный прирост → FAQ прямо определяет разность вероятностей. Старые архивные changes сохраняют историю принятого на тот момент оформления.
