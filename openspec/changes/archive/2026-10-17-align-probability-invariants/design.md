## Context

См. proposal.md. Solver уже суммирует W/N; представление выбирает экстремумы сравнением BigInt. Ответственность компонентов и владение кешем сохраняются.

## Goals / Non-Goals

Проверить точные инварианты независимо от округлённого представления. Новых расчётных метрик и изменений интерфейса нет.

## Decisions

- Сравнивать дроби перекрёстным умножением BigInt и проверять суммы счётчиков. Проверка только процентов пропускает ошибки округления и неверные веса ветвей.
- Проверять все достижимые узлы из поздней позиции валидированного реального журнала, а терминальные исходы — на малых заданных позициях. Отдельно подтвердить достижение разных размеров ветвей, равных долей, паса, единственной выкладки, обоих вариантов рыбы и ничьей.
- Проверить функции лучших/худших вариантов и анализ реального журнала. Solver не менять; искусственно падающий тест на исправном solver не нужен: это исправление контракта и тестовых данных, исключение из порядка красный/зелёный по отсутствию изменения исполняемого поведения.
- Старые архивные changes сохранить как историю; действующее пояснение README и отчёт о прежнем ошибочном тесте исправить. BL-07 с единицами интерфейса остаётся отдельной задачей.

## Risks / Trade-offs

Полный перебор ранних позиций увеличивает время тестов → использовать малые деревья и поздние позиции реального журнала, не выборку вместо расчёта каждой позиции. Исходные JSON не изменять.

## Validation

Профильные проверки: 23 теста. Полный npm test: 60 тестов без ошибок, npm run check и проверка ссылок документации прошли. Проверено 16 925 уникальных позиций продолжения реального журнала и все 16 шагов анализа через HTTP/worker. Веб-интерфейс не менялся; новая браузерная проверка не проводилась.
