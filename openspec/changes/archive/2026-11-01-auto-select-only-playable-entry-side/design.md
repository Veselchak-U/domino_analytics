## Context

GameEntry определяет сторону в dropAction, а совместимость и ориентацию получает через moveForDrop из проверенных подсказок. Мотивация — в proposal.md.

## Goals / Non-Goals

Единый выбор фактической стороны для предпросмотра и отпускания. Правила, отключение недоступных камней и назначение остатков сохраняются.

## Decisions

- dropAction получает переносимый камень явно. Для непустой цепочки проверяет существующие варианты left/right; если допустим ровно один, возвращает его. При двух сохраняет координатный выбор, при нуле остаётся прежний отказ.
- dragover и drop используют один метод; drop передаёт камень из сохранённого локального переноса после очистки временной подсветки. Это не добавляет второго владельца состояния.
- Ориентация остаётся в moveSuggestions, а не вычисляется повторно. Цели остатков возвращаются без изменений.

## Risks / Trade-offs

- Подсказка могла бы показать сторону указателя вместо стороны хода → используется общий resolver, тестируются обе односторонние ситуации и сохранение выбора при двух краях.

Матрица: пустое поле — start; один допустимый край — автоматический выбор; оба — по координате; ни одного — запрет; остатки — прежние цели игроков и набора.
