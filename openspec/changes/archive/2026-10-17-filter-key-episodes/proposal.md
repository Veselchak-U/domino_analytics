## Why
В обзоре нужны только эпизоды, соответствующие выбранному пользователем размеру значения.

## What Changes
- Единый фильтр по модулю значения для всех четырёх категорий, по умолчанию не менее 3 %.
- Включительная точная граница до округления, отбор перед ограничением пятью.
- Изменение порога без повторного расчёта; 0 показывает все ненулевые эпизоды.

## Capabilities
### New Capabilities
Нет.
### Modified Capabilities
- `key-episodes`: общий числовой фильтр обзора.

## Impact
public/quality.js, app.js, index.html, style.css; тесты и README. История, данные и solver сохраняются.
