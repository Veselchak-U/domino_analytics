## ADDED Requirements

### Requirement: Постоянное двухсервисное хранение в Docker Desktop
Локальная поставка Docker Desktop SHALL запускать frontend и backend отдельными контейнерами, публиковать только frontend на loopback и хранить SQLite на постоянном томе backend. Команды остановки, обновления и пересоздания SHALL сохранять загруженные игры и полностью готовые результаты. Резервная копия SHALL содержать согласованное состояние SQLite, включая завершённые записи WAL.

#### Scenario: Пересоздание контейнеров
- **WHEN** импортирована игра, рассчитан раунд и оба контейнера пересозданы без удаления тома
- **THEN** игра присутствует в библиотеке и повтор анализа возвращает кеш без нового worker

#### Scenario: Копия БД
- **WHEN** выполнена команда backup при работающем backend
- **THEN** на компьютере владельца создана отдельно открываемая согласованная копия базы
