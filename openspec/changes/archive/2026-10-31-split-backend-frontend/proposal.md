## Why

Приложение объединяет интерфейс и API в одном сервере, а игры и результаты хранятся только в памяти. Нужны независимо запускаемые фронтенд и бэкенд с постоянной библиотекой партий и быстрым повторным открытием анализа в локальном Docker Desktop.

## What Changes

- Два сервиса Docker Compose: frontend со статикой и HTTP-прокси, backend с REST API и вычислительным worker.
- SQLite в постоянном Docker-томе: исходные журналы, имена файлов, метаданные, задания и полностью готовые результаты раундов, ветвей и упражнений.
- Каталог сохранённых игр в интерфейсе; восстановление готовых раундов после обновления страницы и перезапуска контейнеров.
- Версионированный API /api/v1; прежние /api-маршруты остаются совместимыми.
- Прерванный расчёт помечается ошибкой с возможностью повтора; готовые результаты не теряются. Текущая политика одного worker и 409 для другого расчёта сохраняется.
- Бат-файлы запуска, остановки, обновления, перезапуска, состояния, логов и резервной копии.
- Запуск только локально: frontend опубликован на 127.0.0.1:3210, backend не имеет опубликованного порта. Облака, публичный вход и многопользовательский доступ вне этого изменения.

## Capabilities

### New Capabilities

- `game-library`: постоянный каталог проверенных игр и результатов.
- `analysis-service`: версионированное сохранение анализа и жизненного цикла заданий.
- `service-boundaries`: два приложения, локальный REST, Docker и команды управления.

### Modified Capabilities

- `round-analytics`: повторное открытие игры и анализа через API без повторной загрузки файла.
- `alternative-branches`: сохранённый версионированный кеш ветвей.
- `local-vm-deployment`: расширение поставки двумя сервисами и сохранением SQLite при обновлении.

## Impact

Затронуты src/server.js, общий расчётный код, public/app.js и index.html, запускные скрипты, Docker-поставка, тесты и документация. Встроенный node:sqlite требует Node.js 22.13+; в текущей среде работает Node.js 22.15.1. Игровые формулы, 28 камней, BigInt, полный перебор и исходный kozel-game-v1 сохраняются. Часть BL-12 реализуется, но история силы игроков и межпартийная статистика не добавляются.

Исследование облаков в hosting.md сохранено как справочный материал; текущее изменение не создаёт аккаунтов и ресурсов и не передаёт игровые данные за пределы локального компьютера.
