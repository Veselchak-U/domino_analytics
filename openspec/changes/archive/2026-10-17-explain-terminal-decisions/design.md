## Context
settle в src/game.js — единственное правило начисления. BL-08/BL-21 уже дают локальные последствия и не гарантируют будущие ходы. Каталог источников: сравнение малых остатков из двухместных вариантов не заменяет командного рыбака и контекст партии проекта.

## Goals / Non-Goals
Разбор немедленного терминала, без прогноза рыбы через несколько ходов, внешних эвристик и нового полного перебора.

## Decisions
terminalDecision в src/facts.js применяет кандидат и вызывает settle. DTO хранит прежние score/fence/eggs и outcome; null для нетерминала. analysis.js прикрепляет settlement к каждому кандидату. UI строит отдельный раскрываемый разбор рядом с W/N, подчёркивает причину различия победителей при рыбе. Действующий журнал не переписывается; расчёт и кеш прежние.

## Risks / Trade-offs
Рыбак может отличаться от автора дубля → использовать outcome.finishedPlayer. При eggs нет победителя по правилам → явно не назначен. Окончательная ничья — третий аналитический исход. Стоимость одиночного 0–0 относится к отдельной руке, не сумме пары.
