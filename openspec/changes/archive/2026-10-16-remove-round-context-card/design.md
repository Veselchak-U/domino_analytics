## Context

Карточка статична в HTML, а renderAnalysis заполняет три её DOM-узла.

## Goals / Non-Goals

Goals: удалить карточку без ошибок отображения. Non-Goals: удалять статистику
из API или менять расчёт.

## Decisions

Удалить HTML и три присваивания вместе, убрать неиспользуемый аргумент cached
у renderAnalysis. Задать верхней сводке две колонки; узкий экран сохраняет одну.
Удалить также метрики количества камней/стоимости рук и обращения к ним;
оставшиеся три показателя используют сетку из трёх колонок на широком экране.

## Risks / Trade-offs

Удалённый DOM при старых обращениях ломает показ → проверка нового и кешированного анализа в браузере.
