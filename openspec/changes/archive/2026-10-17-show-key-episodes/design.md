## Context
См. proposal.md. public/impact.js уже сравнивает точные доли, public/quality.js агрегирует качество. app.js владеет analysis и stepIndex; selectStep синхронизирует навигацию, историю и графики.

## Goals / Non-Goals
Цель — производный обзор готового результата без нового расчёта solver. Хранение истории и тренировка остаются отдельными задачами.

## Decisions
- Чистый keyEpisodes в quality.js получает analysis и возвращает четыре списка записанных решений; номер действия i+1 связан с позицией i массива steps. Отдельного состояния выбора эпизода нет: единственный владелец позиции остаётся app.js.
- Fraction из W/N используется и для сравнения, и для отображения. Числовые округлённые probabilities не участвуют в ранжировании. Списки сортируются раздельно, до пяти, равные — по шагу. Общий смешанный рейтинг отвергнут: потеря, влияние и разброс отвечают на разные вопросы.
- Отрисовка списков при renderAnalysis, а не при каждом шаге. Кнопка вызывает selectStep(position) и прокручивает к тайлу кандидатов; он уже показывает реальный следующий ход и лучшие. Описание перед кандидатами явно связывает номер позиции с номером действия.
- Заимствована идея обзора решений Mesa Quince из каталога docs/domino-analysis-sources.md. 2026-10-17 проверен актуальный README https://github.com/Pumpurri/domino-trainer: три игрока, double-nine, скрытые расклады и симуляции. Переносится идея обзора, алгоритм и пороги не переносятся. Наши формулы проверены по актуальным public/impact.js и src/analysis.js, модель полного перебора сохраняется.

## Risks / Trade-offs
- Один ход в нескольких списках → явные названия величин и пояснение.
- Путаница шага до/после → номер действия в кнопке и описание позиции перед ним в тайле; браузерная проверка всех навигаторов.
- Ограничение пятью скрывает менее крупные эпизоды → число указано в пояснении, полная история доступна.
- Раскрытые руки не отражают знания человека → явное пояснение без ярлыков ошибок и сложности.

## Migration Plan
Новые статические UI-блоки и чистая функция; формат данных не меняется. Откат коммита возвращает прежний интерфейс.
