## Context

DFS уже возвращает максимальную глубину в кешируемом результате. См. proposal.md.

## Goals / Non-Goals

Goals: вычислить обе границы за один существующий обход. Non-Goals: менять
счётчики, правила окончания и вероятность; показывать длину только реального пути.

## Decisions

- Добавить minDepth: терминал 0, внутренний узел min(child.minDepth + 1).
  Начальное Infinity допустимо только внутри обработки узла и заменяется при
  первом потомке. Все незавершённые позиции имеют ход или обязательный пас.
- Сохранить depth для совместимости API/CLI; summarize переносит обе границы.
  Новый отдельный обход дублировал бы работу. Владельцы кеша и worker неизменны.
- В карточке две строки с подписями и крупными значениями, сгруппированные
  вертикально, чтобы не сжимать текст на телефоне. Значения берутся из base.

## Risks / Trade-offs

Дополнительное число в каждой кешируемой позиции увеличивает память → минимум
в том же результате, без дополнительной таблицы. Терминальные результаты разделяются.

## Migration Plan

Перезапустить сервер и обновить страницу для нового поля minDepth и очистки кеша.
