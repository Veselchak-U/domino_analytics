## Context

См. proposal.md. Текущий список поднимает actual первым. API уже содержит точные счётчики побед и листьев для всех альтернатив.

## Goals / Non-Goals

Изменить только порядок отображения; сохранить данные анализа, подписи и игровую математику.

## Decisions

Чистая функция в impact.js возвращает отсортированную копию альтернатив. Для команды step.turn % 2 сравниваются точные доли wins/leaves перекрёстным умножением BigInt. База вероятности общая для всех альтернатив, поэтому убывание вероятности эквивалентно убыванию влияния. При равенстве компаратор возвращает 0 и стандартная стабильная сортировка сохраняет порядок. Альтернатива сортировки отображаемых процентов теряет различия при округлении.

## Risks / Trade-offs

Ошибочный выбор команды → тесты для всех четырёх мест. Потеря точности на больших счётчиках → тесты значений выше безопасного диапазона Number и разных знаменателей. Сортировка исходного массива могла бы менять модель → использовать toSorted и проверить отсутствие мутации.
