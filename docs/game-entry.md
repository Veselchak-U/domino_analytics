# Запись партии по ходам

Кнопка «Записать партию» находится слева, рядом с загрузкой JSON. Укажите время начала с часовым поясом, участников по местам 1–4, команды, вариант рыбы и лимит. Партнёры занимают противоположные места. После начала шапка фиксируется на всю партию. Возврат к анализу и повторное открытие формы сохраняют ввод в памяти этой вкладки.

Выберите заходящего и нажимайте подсказки камней с нужным краем. Очередь переключается автоматически; цепочка и список ходов обновляются сразу. Пас доступен только при совместимости с известными данными. «Отменить последний ход» возвращает предыдущую позицию и очищает ввод остатков.

Начальные руки заранее не нужны. Подсказки проверяют стыковку, повторы, очередь, размеры рук и возможность распределить неизвестные камни с учётом всех пасов. Они не подтверждают фактический расклад: полная проверка выполняется после ввода остатков.

Форма сама определяет выход после седьмого камня и рыбу, когда ни один оставшийся камень не подходит к концам, включая дубли. Выберите участника и назначьте ему оставшиеся камни. Карточки показывают, сколько камней нужно каждому. Камень можно снять повторным нажатием для его владельца или переназначить другому. Кнопка назначения всех оставшихся доступна, когда их число равно недостающему количеству выбранного участника.

После распределения всех камней подтвердите раунд. Восстанавливаются четыре начальные руки по семь камней, проверяются все 28 камней, пасы и условия пересдачи, затем полностью воспроизводится журнал. Ошибка сохраняет текущий ввод для исправления. Подтверждённые раунды доступны для просмотра. Показываются начисления раунда, накопленный записанный счёт, забор и банк яиц. Следующий раунд наследует счёт и право захода; после окончания партии отображается победитель или ничья.

## Сохранение и продолжение

- «Скачать JSON» выгружает `kozel-game-v1`. Пока партия продолжается, документ имеет `status: "incomplete"`, не содержит корневого `result`, а имя заканчивается на `_incomplete.json`. Каждый раунд внутри уже завершён и содержит полные `deal`, `moves`, `result`.
- «Загрузить незавершённую партию» проверяет весь такой документ и открывает следующий раунд с прежними общими данными и счётом. Ошибка загрузки сохраняет текущую форму.
- Для законченной партии записываются `status: "complete"` и итоговый `result`. «Скачать и рассчитать с сохранением» сначала скачивает файл, затем запускает существующий точный клиентский расчёт и сохранение исходника и компактных результатов на сервере.

Выгрузка доступна только при наличии хотя бы одного подтверждённого раунда и отсутствии ходов в открытом раунде. Частичный раунд выгружать нельзя. Прежде чем закрыть или перезагрузить вкладку, завершите текущий раунд и скачайте JSON: автоматического сохранения формы между перезагрузками нет. Браузер предупреждает о несохранённом вводе.

Обычная загрузка JSON для анализа и API v1 принимают только завершённые партии. `incomplete` отклоняется по полю статуса независимо от имени файла. Отсутствие `status` в старом документе означает `complete`; явное `complete` не меняет хеш исходника. Формат и правила сверены с [источником спецификации](game-spec-source.md).
