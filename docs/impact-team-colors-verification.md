# Командные цвета графика влияния

17 октября 2026, встроенный браузер, готовый журнал 2026-10-01-19-49-source-012-game-001.json.

- До изменения P3/P4 имели голубой/фиолетовый индивидуальные цвета, отличающиеся от партнёров P1/P2.
- После изменения вычисленные цвета легенды, бейджей, фактических столбцов, всех текстовых параметров, штриховок и точек каждого реального хода совпадают с цветом команды на графике вероятностей. Проверка всех групп SVG не выявила расхождений в обеих темах.
- При выборе ходов P1–P4 описание выбранного шага получает соответствующий цвет команды. При возврате к шагу 0 описание нейтральное.
- Тёмная палитра команд: rgb(98,207,186) / rgb(239,180,107); светлая: rgb(0,111,98) / rgb(151,86,15).
- 55 тестов и npm run check проходят.
