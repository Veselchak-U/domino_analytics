  postinstall устанавливает AST Index и строит индекс.
- `npm test -- --test-reporter=dot`: 28 тестов прошли после исправления кеша.
- `npm run check`: синтаксис всех JS-файлов приложения/тестов/инструментов и ссылки
  проектных правил прошли проверку.
- `npm audit --cache .analysis/npm-cache`: известных уязвимостей зависимостей нет.
- AST Index 3.55.0: version, rebuild, stats, outline, refs и JSON refs проверены;
  итоговый индекс содержит 17 файлов, зависимости не входят. JSON пагинация
  структурных запросов не обрезана. Установочные и проверочные npm-хуки выполнены.

Тесты покрывают точные целые свыше 2^53, зеркальные продолжения, глубину с пасами,
мемоизацию и вытеснение (16 записей против перебора без кеша), оба варианта рыбы,
яйца, приоритет выхода, оставшийся допустимый дубль, рыбака, порог 13,
забор/яйца/запись, итоговую ничью и победителя партии. Проверены схема, повторные
экранированные ключи, очередь, ориентация, номера, имена/места/камни, обрывы,
несовпадение начислений и независимость от порядка объектов JSON.

HTTP-тест проходит реальный worker: отмена, повторный запуск, точный анализ,
повтор из памяти, ошибки входа и восстановление. На каждом реальном шаге
сверяются 28 камней и сумма точных счётчиков побед/ничьих с количеством листьев.
