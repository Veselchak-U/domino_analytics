# BL-04 — качество решений игроков

17 октября 2026 года. Падающие тесты до реализации подтверждены.
76 тестов и npm run check проходят. Проверены точные максимумы и малые потери,
все четыре места, учёт ничьих, знаменатель качества, исключение вынужденных
и равноценных решений, средняя по решениям, замена повторного раунда и неполнота.
HTTP/worker: для каждого игрока реального журнала сумма категорий равна числу
его действий, окончательные показатели согласованы с точными W/N.

Браузер: реальный журнал — готовый итог 1/1; переход по шагам не меняет сводку.
Учебная партия — итог 3/3; после нового расчёта и отмены при 1/3 данные
готового раунда сохранены, все показатели партии обозначены прочерками.
Тёмная тема 1440×1000 и светлая 430×900: таблица прокручивается внутри панели,
страница не переполняется. Для единственного действия нет метки «Лучший»,
строки потери, нулевого влияния и дублирующей сводки; «В игре» сохранено.
