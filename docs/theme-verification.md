# Проверка тем и компактной сводки

17 октября 2026, локальный сервер на 127.0.0.1:3213, встроенный браузер.

- Реальный журнал 2026-10-01-19-49-source-012-game-001.json: рассчитано 7 328 406 исходов, выбран шаг 9 из 15. Переключение светлой/тёмной темы мышью и Enter сохраняет шаг и значения.
- SVG использует новые цвета команд, соответствующие теме; штриховка лучших и точки худших ходов сохраняются, фон заливок соответствует карточке.
- В FAQ сразу видны заголовок и пять тем; темы изначально закрыты. Enter раскрывает выбранную тему независимо от остальных.
- При ширине окна 430px ширина документа и viewport одинакова (415px с полосой прокрутки). Карточка числа ходов занимает 358px из доступных 383px, подписи и оба значения находятся в одной строке. На широком экране карточка занимает 372px из 927px сводки.
- Space переключает тему на узком экране, шаг сохраняется. После перезагрузки восстанавливается выбранная светлая тема.
- После уточнения пользователя тема по умолчанию изменена на тёмную. Повторно проверены восстановление светлого выбора на 127.0.0.1 и тёмная тема без сохранённого выбора на localhost; автоматические тесты проверяют обе системные настройки.
- 46 тестов проходят; npm run check и git diff --check проходят.
