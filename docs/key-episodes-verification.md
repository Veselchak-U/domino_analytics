# BL-05 — ключевые эпизоды

Дата: 2026-10-17. До реализации тест падал из-за отсутствия keyEpisodes.
После реализации: 80 тестов и npm run check проходят. Синтетические случаи
разделяют положительное влияние и потерю, проверяют разные команды и ничьи,
несколько лидеров, точную сортировку больших счётчиков, стабильность равенств,
ограничение пятью, нули, отсутствие записанного действия и неизменность входа.
HTTP/worker проверяет реальные результаты solver: фактический кандидат совпадает
с распределением следующей позиции, знак метрики соответствует категории,
сохраняется связь действия с позицией перед ним.

Браузер, реальный журнал:
- Упущенная возможность хода 9 — 6,55 %, влияние −3,11 %.
- Максимальный рост оценки у хода 15 — +37,88 %, разброс 38,46 %.
- Enter на эпизоде хода 9 открывает позицию 8: обе навигации и активная строка
  истории равны 8, график показывает ход 8; тайл кандидатов явно указывает
  «перед ходом 9», фактический 6–1 справа и лучший вариант.
- На светлом экране 430×900 эпизод разброса открывает позицию 14 перед ходом 15,
  ширина документа 415 при ширине окна 430 — переполнения страницы нет.
- При единственном действии отметка «В игре» остаётся, меток лучшего, потери,
  нулевого влияния и дублирующей сводки нет.

## Общий фильтр, 2026-10-17

82 теста и npm run check проходят. Добавлены проверки порога 3 % по умолчанию,
положительных и отрицательных границ, точного значения чуть ниже 3 % при
отображении 3,00 %, дробного порога, нуля и недопустимых значений. На реальном
solver проверяется модуль значения каждого возвращённого события не менее 3 %.

Браузер: при 3 % потеря хода 4 (2,82 %) отсутствует, при 0 возвращается;
снижение −3,11 % показано, −2,34 % скрыто. Порог 3,5 исключает снижение −3,11 %
и показывает пустую категорию. Изменения порога сохраняют позицию 8 в навигации.
Пустое поле и 101 показывают ошибку; последний допустимый результат сохраняется.
Светлая тема и тёмная при 430×900 проверены; документ шириной 415, переполнения нет.

При переключении на раунд 2 сохранено значение 3,5; списки построены по нему.
