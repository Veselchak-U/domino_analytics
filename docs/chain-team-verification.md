# Командная обводка цепочки

2026-10-17. До реализации тест падал из-за отсутствующего модуля.
99 тестов и npm run check проходят. Проверены обратная ориентация, разные края,
оба партнёра, пустая цепочка, неизвестный и неоднозначный владелец.
Все префиксы реального журнала и трёх учебных раундов, включая пасы, сверены
с авторами записанных действий. Новый статический модуль доступен через HTTP.
Браузер: позиция 10 реального раунда, два разных приглушённых цвета,
названия команд в подсказках; цвета обновляются при смене темы. На ширине
430 документ 415, переполнения нет. Фишки в руках не получают командные классы.
