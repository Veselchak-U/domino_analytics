# Проверки

Порядок: спецификация → падающий поведенческий тест → реализация → зелёный тест.
Тестируй через наблюдаемое поведение; ожидания не должны копировать алгоритм.
Покрывай игровые границы, рыбу обоих вариантов, ничью партии, неверный JSON,
точность счётчиков, дедупликацию, кеш и реальные журналы. Синтетические примеры
используй с независимо известным результатом. Реальные журналы сверяй воспроизведением.
Во время работы запускай затронутые тесты. На итоговом состоянии — npm test и
npm run check; повторяй после влияющих на результат правок, а не без изменений.
Веб-интерфейс проверяй в браузере, если доступен; недоступную проверку обозначай явно.
Закрывай серверы и workers в тестах. Документация требует проверки текста и ссылок.
